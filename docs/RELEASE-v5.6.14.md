# Carb 5.6.14 · Windows x64

修复窗口启动失败与渲染进程崩溃后的恢复，完善本地核心服务启动重试。

## 本次修改

- 窗口启动、页面加载失败或渲染进程退出时，桌面端会捕获错误。自动恢复连续失败达到上限后，可以按窗口内提示手动重载。
- 本地核心服务启动时的同步错误与异常退出统一走有限次数的延时重试。关闭程序时会取消恢复计时。
